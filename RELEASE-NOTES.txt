1.1.17
- Policy lists: From and To are now dates typed as dd/mm/yyyy (or picked from the calendar), so part of a month can be exported, e.g. 01/11/2026 to 15/11/2026.
- A file that does not cover whole months is named <line>-<dd.mm>_<dd.mm>-<year>.xlsx, e.g. 01-01.11_15.11-2026.xlsx.

1.1.16
- Faster "Checking PIAS" when PIAS has to start: no fixed 15 s wait after login, and a login press PIAS ignores is retried after 10 s instead of 60 s.
- The log now shows how long PIAS took to start and log in.

1.1.15
- New Settings button at the bottom of the left bar. It opens a dialog over the page with General (language), Appearance (theme, font, text size), Updates.
- Update is no longer an item in the tool list; the update banner opens Settings > Updates.

- The folder picker now opens in front of the app window instead of behind it.

1.1.4
- One page for everything: 'Tìm kiếm đơn bảo hiểm' is now a group in the left column next to the
  report groups, instead of a separate page. Pick it to list policies, pick a report group to export reports.

- 'Revenue only' shows only for the business-performance group it applies to.
- The log is collapsed by default; click it to open. Report and line lists are taller, less empty space.

1.1.3

  slashes no longer fails with "the file name is not valid".

1.1.2

  is skipped when PIAS is already up on the year being exported. About twenty seconds a report.

1.1.1
- Before a report runs, 'Noi dung duoc chon' in its settings box is emptied. PIAS keeps what was
  chosen the last time, and anything left there filters the report without saying so.
- The unit filter is now checked both ways: the tool refuses to run a report when the box cannot be
  emptied, or when PVI Digital did not move across.
- app\data\pias_recipes.json: what each of the 190 reports asks for, read off its settings box
  without running anything. 187 of them want the same thing: two dates and one list filter.
